## Improvements in 0.2.3 (LATEST)

**CRITIQUE: Fix file opening crash**
- Use cmd /c start instead of explorer.exe for proper file associations
- Files now open with correct default applications
- No more app crash when clicking on files
- CREATE_NO_WINDOW flag to avoid console popup

**MAJOR: Expanded search coverage**
- Added Pictures, Videos, Music, OneDrive to default paths
- Now indexes Program Files and Program Files (x86)
- Increased to 8 threads for faster indexing (was 4)
- Increased max file size to 50MB (was 10MB)
- Much more comprehensive system coverage

**MAJOR: Better search UX**
- Works with 1+ character now (was 3+)
- Smart wildcard: *query* for 1-2 chars, query* for 3+ chars
- Content search properly enabled and working
- Search 3x more results then rank them (better quality)
- More permissive query parser

## Bug Fixes in 0.2.2

**CRITIQUE: Fix "there is no reactor running" panic**
- Removed Rayon + Tokio::spawn mixing that caused runtime panic
- Simplified scanner to use sequential async indexing
- No more reactor context errors during file indexing
- Scanner now properly runs in Tokio runtime context

**Code cleanup**
- Removed unused imports and dead code warnings
- Cleaner codebase with no compilation warnings

## Bug Fixes in 0.2.1

**CRITIQUE: Correction du crash "Cannot start a runtime from within a runtime"**
- Refonte complète de l'architecture UI avec channels async
- Thread de recherche dédié avec son propre runtime Tokio
- Plus de blocage dans le thread principal UI
- Correction du freeze PC au lancement

**Optimisations par défaut**
- Chemins d'indexation réduits (Documents/Desktop/Downloads seulement)
- Limite de 4 threads max pour l'indexation
- Taille max des fichiers réduite à 10MB
- NOTE: Ces valeurs sont PERSONNALISABLES dans config.toml
